COMMENTS ON CODE QUALITY:


* Code is highly cohesive allowing the creation or addition of new tiles and rooms, though this process is required to be hard coded rather than relying on an outside file format like CSV or XML. Use of magic numbers should be changed to constants. RoomSpawns.AddTo relies heavily on matching integer indices from DungeonRooms (index + 1). If someone reorders or shifts a layout in the map spreadsheet array, the spawn points silently map to the wrong room configurations.


HYPOTHETICAL CHANGE:
Use of a CSV or XML file for creating the rooms would make adding and storing rooms easier in the long run and allow the replacement or addition of new files by users to create custom dungeons. Instead of having a separate class for SecondRoom it should be part of the CSV. Replace the floating point magic numbers with constants.
